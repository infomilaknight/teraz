# طِراز — Teraz

ثيم أزياء لمنصة **سلة**، مبني على محرك Twilight. عربي أولاً (RTL) بواجهة إنجليزية كاملة،
واتجاه تجاري نظيف عالي التحويل.

## الحالة

| المرحلة | الحالة |
|---|---|
| اختيار الاتجاه والهوية | ✅ مكتمل |
| تصميم الشاشات (كانفاس تفاعلي) | ✅ مكتمل |
| أصول الديمو (صور + فيديو) | ✅ مكتمل |
| تنفيذ Twig / Tailwind | ⏳ لم يبدأ |
| مكوّن `home.hero-video` في `twilight.json` | ⏳ لم يبدأ |

القاعدة الحالية هي `theme-raed` الرسمي بدون تعديل بصري بعد — الالتزام مقصود: كل أسماء
الكلاسات (`s-product-card-*`, `btn--*`) وبنية `views/` تفضل زي ما هي عشان مكوّنات سلة
الجاهزة تشتغل، والتغيير يكون في القيم البصرية فقط.

## نظام التصميم

| العنصر | القيمة |
|---|---|
| اللون الأساسي (افتراضي) | `#16161A` — يُحقن من لوحة تحكم التاجر عبر `--color-primary` |
| الخلفية | `#FAF9F7` (ورق دافئ) |
| الحدود | `#E6E4E0` — حدود شعرية بدل الظلال |
| التخفيض / الثقة | `#C0261E` / `#0E6B4F` |
| الخطوط | Readex Pro (عناوين) + IBM Plex Sans Arabic (نص) — يُستبدل بـ `--font-main` |
| الحواف | 4 شارات · 8 أزرار وحقول · 10 بطاقات · 999 رقائق |
| عرض الحاوية | 1280px |

## الأصول

- `src/assets/images/demo/` — ٢٨ صورة مولّدة (`gemini-3-pro-image`): هيرو، منتجات ٤:٥،
  تفاصيل خامة، ٤ ألوان للعباية، لوك بوك، أقسام، بنرات.
- `src/assets/videos/hero.mp4` — فيديو الهيرو، ٨ ثوانٍ صامت ١٤٤٠×٦٢٠ (`veo-3.1`).
  نسخة المصدر ١٠٨٠p محفوظة محلياً وغير مرفوعة (انظر `.gitignore`).
- `design/` — لوحات التصميم المصدرية (`*.dc.html` + `canvas.json`) وصفحة الكانفاس المنشورة.

## التشغيل

```bash
npm i -g pnpm          # المشروع يفرض pnpm عبر only-allow
pnpm install
npm i -g @salla.sa/cli
salla login
salla theme preview    # أو: salla theme p
```

## البناء

```bash
pnpm run watch         # تطوير
pnpm run prod          # إنتاج
```
