# أصول العرض — Teraz

محتوى **تسويقي وتجريبي** لصفحة الثيم في متجر سلة ولقطات العرض. مش أصول تشغيل.

مقصود إنه يعيش برّه `src/assets/` عشان `copy-webpack-plugin` بينسخ كل حاجة تحت
`src/assets/images/` إلى `public/`، وده معناه إن أي صورة هنا كانت هتترحّل مع الثيم
لمتجر كل تاجر بدون داعي (٨٩٢ ك.ب).

| المجلد | المحتوى |
|---|---|
| `images/` | ٢٨ صورة أزياء مولّدة (`gemini-3-pro-image`) — هيرو، منتجات ٤:٥، تفاصيل خامة، أربع درجات لون للعباية، لوك بوك، أقسام، بنرات |
| `videos/hero.mp4` | فيديو الهيرو، ٨ ثوانٍ صامت ١٤٤٠×٦٢٠ (`veo-3.1`) — ٨٩٢ ك.ب |
| `videos/hero-source-1080p.mp4` | نسخة المصدر ١٠٨٠p (محلية، مستبعدة من الريبو) |

## استخدام الفيديو في مكوّن «هيرو فيديو»

المكوّن بيقرأ رابط، مش ملف من الثيم — عشان التاجر يقدر يغيّره بدون نشر نسخة جديدة:

1. ارفع `videos/hero.mp4` في **المتجر ← الملفات** بلوحة تحكم سلة.
2. انسخ الرابط والصقه في حقل «رابط الفيديو (MP4)».
3. ارفع `images/hero-video-poster.jpg` في حقل «صورة الغلاف».
